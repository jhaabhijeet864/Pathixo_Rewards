# Pathixo Rewards — Public Product Roadmap

Pathixo Rewards turns waiting time during AI generation into cash rewards for users and high-attention inventory for advertisers.

---

## Current Status: Milestone v0.1.0 (Completed)

- [x] **Manifest V3 Multi-Browser Extension**: WXT + TypeScript core supporting Chrome, Edge, and Firefox.
- [x] **5 AI Platform Adapters**: Content script detection for ChatGPT, Claude, Gemini, Perplexity, and DeepSeek.
- [x] **Shadow DOM Ad Card**: Zero-`innerHTML` isolated inline card with instant dismiss button.
- [x] **Anti-Fraud Dwell Timer**: Client-side verification requiring active foreground focus and 4+ contiguous seconds.
- [x] **Extension Popup UI**: Live balance, status toggle, 1-click referral copy, and cashout shortcut.
- [x] **Web Platform (Next.js 15)**: Anti-AI-slop landing page, live mock generator, and clean earnings estimator.
- [x] **Self-Serve Advertiser Portal**: Live multi-chatbot ad previewer, CPM calculator, and campaign setup (`/advertise`).
- [x] **User Earnings Dashboard**: Balance, impression history, referral metrics, and $2.00 instant cashout terminal (`/dashboard`).
- [x] **Dynamic Selector Sync**: Edge-cached remote selector updates to patch AI DOM changes without store review delays.
