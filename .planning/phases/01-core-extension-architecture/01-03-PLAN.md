# Plan 01-03: Perplexity & DeepSeek Adapters + Remote Selector Configuration Engine

## Goal
Implement site adapters for Perplexity and DeepSeek, complete the content script orchestrator, and wire up the dynamic remote selector configuration engine to ensure resilient, real-time patchability across all 5 AI chatbots.

## Context
Adding Perplexity and DeepSeek gives Pathixo Rewards an immediate competitive edge over Chatwait (which only supports 3 chatbots). Furthermore, AI websites frequently update their DOM class names. Rather than waiting 3-5 days for Chrome Web Store extension reviews every time an AI provider updates its UI, Pathixo Rewards uses an edge-hosted JSON selector dictionary cached locally, falling back to bundled defaults if offline.

<task id="2">

<task id="3">
<title>Implement Remote Selector Configuration Engine & Content Script Orchestrator</title>
<action>
1. Create `apps/extension/entrypoints/content/remote-config.ts`:
   - Define fallback default selector table for all 5 domains (`chatgpt.com`, `claude.ai`, `gemini.google.com`, `perplexity.ai`, `chat.deepseek.com`).
   - Implement `fetchRemoteSelectors()`: Checks `browser.storage.local` for cached selectors; periodically syncs against `/api/config/selectors` (with 6-hour TTL).
   - Allows adapters to query dynamic selectors at runtime, instantly adapting to host DOM changes.
2. Create `apps/extension/entrypoints/content/index.ts`:
   - Identify active domain based on `window.location.hostname`.
   - Instantiate matching adapter (ChatGPT, Claude, Gemini, Perplexity, or DeepSeek).
   - Initialize `ad-card.ts` Shadow DOM container.
   - Coordinate submit -> render ad card -> completion lifecycle.
</action>
<verify>
Verify content script entrypoint dynamically selects the correct adapter for the active host, loads remote/fallback selector configs, and compiles under WXT without errors.
</verify>
</task>
