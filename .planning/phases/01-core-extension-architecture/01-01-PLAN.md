# Plan 01-01: Monorepo Setup, WXT Extension Scaffolding & Shadow DOM Ad Card Renderer

## Goal
Establish the Pathixo Rewards monorepo workspace, configure the WXT Manifest V3 browser extension with strict Chrome Web Store compliance, define shared TypeScript contracts, and implement the isolated Shadow DOM ad card component.

## Context
Pathixo Rewards requires an open-source, ultra-lightweight client that injects non-blocking sponsored cards into AI chatbot streams. To guarantee Chrome Web Store approval, the extension must enforce:
1. Zero remote JavaScript execution.
2. Pure DOM node creation (`document.createElement` / `textContent`) with zero `innerHTML` usage.
3. Complete style encapsulation via open Shadow DOM (`element.attachShadow({ mode: 'open' })`).
4. Strict single-purpose permissions (`storage` only, plus targeted `host_permissions`).

## Tasks

<task id="1">
<title>Initialize pnpm monorepo workspace and shared type contracts</title>
<action>
1. Create root `package.json` with pnpm scripts (`dev`, `build`, `typecheck`).
2. Create `pnpm-workspace.yaml` configuring `apps/*` and `packages/*`.
3. Create root `tsconfig.base.json` with strict TypeScript configuration.
4. Create `packages/shared/` containing shared TypeScript types:
   - `AdCreative`: `id`, `headline`, `sponsor_name`, `url`, `icon_url`, `is_house_ad`, `target_cpm`, `ad_token`.
   - `ImpressionEvent`: `event_id`, `ad_id`, `ad_token`, `device_id`, `timestamp`, `dwell_ms`, `ai_platform`.
   - `PromptAdapter`: Interface defining `start`, `stop`, `hostAdVisible`, and callbacks (`onSubmit`, `onAnchorReady`, `onReanchor`, `onDone`).
   - `RemoteSelectorConfig`: Mappings for each supported AI domain's composer, send button, stop button, and user message bubble.
</action>
<verify>
Run `pnpm -v` and verify workspace structure and TypeScript type exports in `packages/shared`.
</verify>
</task>

<task id="2">
<title>Scaffold WXT Manifest V3 browser extension</title>
<action>
1. Scaffold `apps/extension` using WXT (`wxt` and `typescript`).
2. Configure `apps/extension/wxt.config.ts`:
   - Manifest name: "Pathixo Rewards: Get paid while AI thinks".
   - Version: "0.1.0".
   - Permissions: `["storage"]`.
   - Host permissions:
     - `https://chatgpt.com/*`
     - `https://claude.ai/*`
     - `https://gemini.google.com/*`
     - `https://www.perplexity.ai/*`
     - `https://chat.deepseek.com/*`
   - Build outputs: `.output/chrome-mv3` and `.output/firefox-mv2`.
3. Generate and place extension branding icons (16px, 32px, 48px, 96px, 128px) in `apps/extension/public/icon/`.
</action>
<verify>
Inspect `apps/extension/wxt.config.ts` to ensure manifest permissions and host permissions conform to Manifest V3 without broad permissions.
</verify>
</task>

<task id="3">
<title>Implement isolated Shadow DOM ad card component</title>
<action>
Create `apps/extension/entrypoints/content/ad-card.ts`:
1. Use `element.attachShadow({ mode: 'open' })` on a lightweight custom container.
2. Injected CSS strictly scoped to `:host`:
   - Flex row layout, clean border-bottom, responsive dark/light mode typography.
   - Sponsor icon container (20x20 rounded).
   - "Sponsored • via Pathixo Rewards" attribution micro-tag.
   - Dismiss ("×") button with hover opacity and focus-visible ring.
3. DOM construction: Build all nodes using `document.createElement`, setting text with `.textContent` and attributes via `.setAttribute` / `.href` / `.src`. Never pass strings into `.innerHTML`.
4. Card Lifecycle methods:
   - `mount(anchorEl: HTMLElement)`: Places the card immediately following the user turn.
   - `render(ad: AdCreative)`: Binds ad data, clicks, and dismissal handlers.
   - `unmount()`: Gracefully tears down listeners and removes DOM node.
</action>
<verify>
Verify unit test or DOM assertions for `ad-card.ts` ensuring shadowRoot attachment, no `innerHTML` references, and clean mount/unmount logic.
</verify>
</task>
