# Plan 04-01: Self-Serve Advertiser Campaign Portal

## Objective
Build `/advertise` allowing sponsors to configure ad campaigns, preview creatives live in simulated ChatGPT/Claude UI frames, and top up ad balances via Stripe.

## Tasks
1. Build campaign form on `/advertise` (headline, brand name, destination URL, icon, CPM bid, budget tier).
2. Implement live side-by-side interactive preview rendering inside simulated ChatGPT and Claude conversation mockups.
3. Wire up campaign submission endpoint `POST /api/campaigns`.
4. Write unit tests for campaign creation and budget verification.
