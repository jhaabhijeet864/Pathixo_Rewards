# Plan 04-02: User Dashboard & Instant $2 Cashout Terminal

## Objective
Build `/dashboard` enabling users to view live earnings, track impressions, copy referral links, and execute instant cashouts with a $2.00 floor via UPI, PayPal, or Gift Cards.

## Tasks
1. Build dashboard layout with key metrics (current balance, lifetime earnings, today's views, referral credits).
2. Implement $2.00 cashout terminal (`POST /api/cashout`) supporting UPI (instant in India), PayPal, and Digital Gift Cards.
3. Build Referral Hub displaying 10% bonus statistics and device link manager.
4. Write unit tests for cashout threshold enforcement and earnings query.
