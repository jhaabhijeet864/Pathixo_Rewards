# Plan 02-02: Anti-Fraud Dwell Verification & Impression Ingestion

## Objective
Implement client and server verification requiring $\ge 4000\text{ ms}$ continuous focused visibility (`document.visibilityState === 'visible'`) before logging qualified impressions.

## Tasks
1. Implement dwell time tracker in `entrypoints/content/index.ts` tracking `cardStartTime` and `visibilitychange` events.
2. Ingest events at `POST /api/events/impression`, rejecting events under 4000ms or lacking valid signed tokens.
3. Credit 60% user revenue share ($0.009 USD per qualified impression on $15 CPM).
4. Write unit tests for dwell qualification thresholds and impression ingestion logic.
