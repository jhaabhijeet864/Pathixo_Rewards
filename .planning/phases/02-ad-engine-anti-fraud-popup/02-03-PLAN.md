# Plan 02-03: Extension Popup UI & Device Synchronization

## Objective
Build the extension popup UI providing real-time earnings display, master toggle switch, today's impression counter, 1-click referral copy, and account dashboard navigation.

## Tasks
1. Construct popup HTML structure matching modern consumer aesthetic (`entrypoints/popup/index.html`).
2. Style popup using CSS variables, card containers, toggle switch, and typography (`entrypoints/popup/style.css`).
3. Implement `main.ts` connecting background message broker (`GET_STATE`, `SET_ENABLED`, `OPEN_DASHBOARD`).
4. Wire up 1-click clipboard referral copy with real device ID.
