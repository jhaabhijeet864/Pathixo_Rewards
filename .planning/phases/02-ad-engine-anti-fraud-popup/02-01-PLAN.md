# Plan 02-01: Ad Engine API & Inventory Delivery

## Objective
Deliver backend endpoints for distributing ad bundles (`/api/ads/bundle`) with cryptographically signed tokens and serving remote DOM selectors (`/api/config/selectors`).

## Tasks
1. Define TypeScript schemas for `AdCreative` and `RemoteSelectorConfig` in `@pathixo/shared`.
2. Implement Next.js 15 route handler `GET /api/ads/bundle` returning active campaigns and high-converting affiliate fallbacks (Cursor, Perplexity Pro, Notion, v0).
3. Implement `GET /api/config/selectors` with edge caching headers (`Cache-Control: public, s-maxage=3600`).
4. Write unit tests for bundle response and selector validation.
